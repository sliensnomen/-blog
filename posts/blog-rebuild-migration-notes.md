我的博客迁移史，差不多就是一部「从一个坑跳到另一个坑」的血泪史。

## 第一代：Hexo

大学时候用的。主题多，插件多，部署到 GitHub Pages 也很方便。

问题是：

- Node 版本一升级就报错
- 主题升级经常破坏自定义样式
- 写文章的体验一般

## 第二代：Astro + astro-paper

今年年初试的。静态生成、速度快、SEO 友好，我一度觉得这就是终点。

但用了两个月之后，我发现自己真正想要的不是一个「阅读优先」的博客，而是一个能放跑团日志、项目展示、音乐播放器、照片墙的「个人空间站」。

astro-paper 太干净了，干净到有点空。

## 第三代：XHBlogs

现在用的这个。Next.js + FastAPI，有前端展示，也有本地管理后台。

吸引我的点：

- 毛玻璃风格，视觉上很对味
- 有 Moments、Chatters、Projects、Friends 等模块
- 自带编辑器，写文章方便
- 可以本地运行管理后台

## 现在的配置

- 前端：Next.js 16 + Tailwind 4
- 后端：FastAPI + Python 3
- 部署：本地 systemd 服务 + GitHub 备份
- 运行端口：3000（前端）/ 39998（后端）

## 未来想加的功能

- 自动把 Moments 同步到 Mastodon
- 文章里的代码块支持更多语言高亮
- 给 Projects 页加上 GitHub 数据自动拉取

## 写在最后

换博客系统不是目的，目的是找到一个让自己愿意持续写东西的地方。

希望这次能久一点。

> 精灵小姐：「你上次也这么说。」
>
> 我：「但这一次，我有 systemd 开机自启。」
